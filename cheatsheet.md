# Pyramid Structure: Reasoning Cheatsheet

## Decision Rules

- State the **governing thought** first; it summarizes everything below.
- Each level answers: **Why? How? Why do you say that?**
- Keep groups wholly **deductive** or **inductive**.
- Apply the **plural-noun test**: one precise label fits every point.
- Prefer 4–5 points; subgroup longer lists.
- Summarize actions by observable effect; situations by shared implication.
- Keep familiar history in the introduction and new reasoning in the body.
- Use idea-bearing headings.
- Discover **bottom up**; communicate **top down**.

## Choose the Structure

```text
Can you state the reader’s Question and likely Answer?
├─ Yes → The Top-Down Approach
│  Subject → Situation → Complication → Question → Answer
│  → ask the New Question → build the Key Line
└─ No → The Bottom-Up Approach
   List points → find relationships → deduplicate
   → group and order → summarize upward → infer Answer
   → rebuild Situation–Complication–Question–Answer
```

```text
For each point:
Question raised? → direct answers → deduction or induction
→ logical order → summary above
→ stop when no relevant question remains
```

## Logical-Order Test

| Group formed by | Use | Test |
|---|---|---|
| Statements yielding an implication | **Deductively** | Does “therefore” follow? |
| Actions, stages, causes and effects | **Chronologically / Time Order** | Must one precede another? |
| Parts of a whole | **Structurally / Structural Order** | Are they **MECE**? |
| Ranked members of one class | **Comparatively / Degree Order** | What shared trait determines rank? |

> Interchangeable points signal unfinished logic.

## Deduction vs. Induction

| Decision | **Deductive Grouping** | **Inductive Grouping** |
|---|---|---|
| Choose when | Meaning requires successive reasoning | Like points support an inference |
| Build | Situation → related statement → conclusion | Like points → plural noun → significance |
| Validate | Point 2 comments on point 1; both yield the conclusion | One class; inference stays within evidence |
| Place | Usually low | Usually on the **Key Line** |
| Limit | ≤4 points or two “therefore” steps | Usually 4–5; subgroup longer lists |
| Reject when | No causality or chain is too long | Vague category, misfits, or overbroad summary |

## Problem-Definition Flow

```text
Opening Scene → Disturbing Event → R1 (Undesired Result)
                                      ↓
                              R2 (Desired Result)
                                      ↓
                    What has already been tried or decided?
```

| Condition | Governing Question |
|---|---|
| No solution | How do we move from R1 to R2? |
| Solution proposed | Is it right? |
| Solution accepted | How do we implement it? |
| Solution failed | What now? |
| Alternatives recognized | Which should we choose? |
| Objectives unclear | What should objectives and strategy be? |
| Gap uncertain | Is there a problem, and how should we respond? |

**Sequential Analysis**

```text
Is there a problem? → Where? → Why?
→ What could we do? → What should we do?
```

- **Diagnostic Frameworks** answer “where/why” through MECE yes-no cause questions and decisive evidence.
- **Logic Trees** answer “what could/should we do.”

## Tells and Smells

| Smell | Decision |
|---|---|
| Details before meaning | Move summary upward |
| “Three issues” | State the insight |
| Mixed idea types | Separate them |
| Long flat list | Subgroup logically |
| Causes mixed with effects | Rebuild vertically |
| Vague action | Name the observable result |
| Introduction needs proof | Move it to the body |
| Complication triggers no Question | Rewrite the story |
| Recommendation last | Move it upward |
| No order or summary | Thinking is incomplete |

## Validation Checklist

- [ ] Top point answers one reader Question.
- [ ] **Situation–Complication–Question–Answer** is credible.
- [ ] Each higher point summarizes all and only its support.
- [ ] Lower groups answer the question above.
- [ ] Groups contain one kind of idea.
- [ ] Groups are deductive or inductive.
- [ ] Every group has logical order.
- [ ] Structural divisions and action sets are MECE.
- [ ] Actions name results; situations name implications.
- [ ] Headings and layout mirror the pyramid.
- [ ] Prose states concrete nouns and relationships directly.
